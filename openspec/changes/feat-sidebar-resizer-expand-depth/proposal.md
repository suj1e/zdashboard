# 提案:侧边栏拖拽调宽 + 默认展开深度可配置(feat-sidebar-resizer-expand-depth)

## 需求复述

用户反馈两点(2026-08-29,view 插件浏览体验):

1. **侧边栏没有 splitter**:宽度固定 `--sidebar-w: 280px`(globals.css:45),不能拖拽拉宽/缩短。
2. **默认展开深度是多少、可不可调**:现状 = 服务端 `spec-scan.ts` 硬编码 2 层(深度 > 2 的目录初始折叠),且 v2.8.0 重构后无任何配置入口。

## 要解决的问题

1. 宽目录/长文件名的项目在 280px 下截断严重,需要能拉宽;小屏想收窄省空间。
2. 深浏览习惯的用户想默认展开更多层,少点几次;反过来想默认全收。

## 成功标准

1. SidebarFrame 桌面态右缘有拖拽把手:拖动实时调宽,范围 **220–480px**;双击把手恢复默认 **280px**;宽度持久化(localStorage `zd-sidebar-w`),刷新保持;移动端(< sm,抽屉模式)不显示把手、不受影响;折叠态不受影响。
2. view 插件新增配置「默认展开深度」(select:1/2/3/4,默认 2),改动即时生效于下次树渲染;所有 worktree 分组树一致应用。
3. 三主题 × 明暗下拖拽把手视觉正常(语义 token);既有测试全绿;新增交互有组件测试。

## 非目标

- 不做右侧内容区 splitter(阅读区固定)。
- 不做可折叠分栏记忆以外的布局持久化。
- 不恢复 hiddenDirs/showHidden 旧配置项(未被消费,重立需另立项)。

## 依赖

- 无前置(基于 main@2.8.1)。

## 优先级

- P2:浏览体验增强,体量小。

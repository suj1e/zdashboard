# 提案:灵感市场插件(feat-inspiration-market)

## 需求复述

用户初衷(2026-08-29,经四轮澄清收敛):**做一个用来找灵感的独立插件**——浏览开源的设计资产,核心价值是「**可以转提示词**」:看上一个 Logo/动效/页面,一键生成结构化提示词喂给 zdesign 生成同类作品。

- 资产来源:**开源**(互联网公开资源,非本地目录)
- 形态:**独立插件**(mode: market)
- 动效载体:**CSS 动效**(排除 Lottie,不引 lottie-web 重依赖)
- 体验:**网格浏览 + 详情 + 转提示词**(转提示词是核心闭环)

## 三个市场的 v1 数据源(经可达性探针后定稿)

| 市场 | 来源 | 获取方式 | 为什么 |
|---|---|---|---|
| **Logo 市场** | Simple Icons(≈5000+ 品牌 SVG,CC0)| jsdelivr CDN 直取单个 SVG;图标名册走 `data.jsdelivr.com` 目录接口 | 完全开源、零维护、无需 npm 依赖 |
| **动效市场** | animate.css / hover.css(MIT 稳定 CSS 库)| jsdelivr 直取库 CSS,插件内置**精选目录**(名称/类名/描述/标签) | CSS 即事实源,预览器实时播放,提示词可直接内嵌源码 |
| **设计灵感** | 精选开源站点/模式目录(GitHub awesome 系、知名开源项目官网)| **内置目录 JSON**(v1 约 30–50 条:url/名称/描述/标签)| 第三方站点多数禁止 iframe(X-Frame-Options),诚实做法是「元数据浏览 + 新窗口打开」,不做内嵌截图抓取 |

## 要解决的问题

1. 找灵感要在多个网站间来回翻,没有统一的浏览/搜索入口。
2. 看到好东西后「转成给 AI 的提示词」全靠手打;动效的 CSS 源码、Logo 的造型特征都应该程序化进提示词。

## 成功标准

1. 独立插件 `market`(mode: market,icon 🛒 或 ✨,order 40),IconRail/HomeGrid 出现。
2. 三市场 Tab(Logo/动效/设计灵感):
   - Logo:搜索框(按名称过滤)+ 网格(SVG 渲染)+ 点击详情(大图/源码/品牌名)+ 「转提示词」;
   - 动效:精选目录网格 + 每项**实时播放**(demo 元素应用该 CSS 类)+ 源码查看 + 「转提示词」(内嵌 CSS 源码);
   - 设计灵感:目录网格(名称/描述/标签)+ 「转提示词」(基于元数据模板)+ 新窗口打开原站。
3. 「转提示词」= 生成结构化提示词文本并复制到剪贴板(toast 确认),模板按市场定制、可编辑后再复制。
4. 外部内容经 **server 代理**获取(allowlist:cdn.jsdelivr.net/data.jsdelivr.com,防 SSRF;带超时与内存级短缓存);网络不可达时降级为缓存/空态,不崩。
5. 零新 npm 依赖(CSS 动效播放用原生 CSS;SVG 用 img/object 渲染);基线测试全绿 + 新增测试。

## 非目标

- 不做本地资产管理(design 插件已覆盖)。
- 不做 Lottie/视频动效、不做用户上传/收藏/登录。
- 不做任意 URL 代理(仅 allowlist)。
- 设计灵感目录 v1 为内置精选,不做远程目录热更新(结构预留)。

## 依赖

- 无前置。
